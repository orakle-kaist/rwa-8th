# 인간 검토 메모

상태: **검토 준비 완료(review-ready)**
기준일: 2026-08-17
대상: 기관용 마스터 제안서와 저장소 루트의 세부 설계·구현 명세

## 이번 개정 결과

- 최종 후보를 기관·학회 구성원이 읽는 사람용 마스터 제안서로 명확히 하고, 구현의 규범적 기준은 별도 설계와 명세에 유지했다.
- 최종 후보에서 계약명, 데이터 필드, 상태값, API·스키마와 코딩표준을 제거하고 업무 흐름과 선택 이유 중심으로 전면 재작성했다.
- SEC의 발행인 주도형·제3자 수탁형·합성형 분류를 쉬운 비교표로 설명했다.
- Dinari를 특정 벤더 채택안이 아닌 제3자 수탁형의 대표 공개 사례로 추가했다.
- Dinari Inc., Dinari Securities와 Alpaca Securities의 이전대리·브로커·청산·수탁 역할을 구분했다.
- 1:1 수량 일치가 직접 주주 지위, 도산절연이나 무위험을 뜻하지 않는다는 한계를 가까이 표시했다.
- Dinari 공개 문서의 체결 후 발행과 본 PoC의 KSD 결제·수탁 반영 후 발행을 비교하고, 더 보수적인 기존 발행 게이트를 유지했다.
- Dinari의 국제 dShares 수탁권리 설명과 미국용 이전불가 보조기록 제안을 구분해, 같은 기술도 관할·상품약정에 따라 권리효과가 달라짐을 반영했다.
- 홍콩은 교체 가능한 첫 판매관할 사례이며 Dinari는 교체 가능한 비교사례라는 중립성을 유지했다.

## 근거 검토

- 제공된 Dinari PDF는 ChatGPT 대화 출력물이므로 조사 단서로만 등록했다.
- Dinari의 이전대리인 등록은 SEC EDGAR, 브로커딜러 등록과 Alpaca 관계는 FINRA BrokerCheck로 확인했다.
- 1:1 수탁, 발행·환매 흐름, 이전제한, 배당·주식분할은 Dinari 공식 제품문서로 확인했다.
- 2026년 미국용 보조기록 구조는 SEC에 게시된 Dinari 제출서로 확인했으며, 회사의 확인요청이지 SEC의 승인이나 답변은 아님을 표시했다.
- 회사 문서에서 확인한 1:1 수탁과 권리 설명은 회사 주장으로 표시했다. 실제 계좌, 감사보고서와 도산절연은 검증됐다고 표현하지 않았다.
- “Dinari가 기초주식 최종 결제 후에만 발행한다”는 주장은 공개자료로 확인되지 않아 채택하지 않았다.

## 실행된 검증

- 로컬 설계 검증: JSON·JSONL·YAML, 스키마, fixture, 14개 원본 체크섬, 로컬 링크와 PII 규칙 통과
- 최종 후보 가독성 검증: 구현 식별자와 코드 마크업 비포함 확인
- 벤더 중립성 검증: 구현 명세에 Dinari 식별자·의존성 없음 확인
- Redocly: OpenAPI 유효
- AsyncAPI CLI: AsyncAPI 3.1.0 유효, governance issue 없음
- gherkin-lint: 핵심·실패 feature 통과
- RWA 리서치 validator: base 및 candidate gate 통과
- git diff whitespace 검사 통과

## 사람이 확인할 판단

1. 최종 후보를 “사람용 마스터 제안서”, 세부 설계·명세를 “구현의 규범적 기준”으로 구분한 문서 체계가 적절한가.
2. Dinari를 가장 우수하거나 유일한 모델이 아니라 대표 공개 사례로 소개한 수준이 중립적인가.
3. 투자자 경험보다 무담보 발행 방지를 우선해 KSD 결제·수탁 반영 후 발행하는 선택에 동의하는가.
4. 1:1 수량대사와 직접 주주 지위·도산절연을 분리한 법적 경계가 기관 설명에 충분히 명확한가.
5. 국제 dShares 수탁권리와 미국 보조기록 제안을 구분한 설명이 관할별 상품설계 필요성을 이해하는 데 도움이 되는가.
6. 현금배당만 핵심 기업행동으로 구현하고 주식분할은 후속범위로 두는 것이 타당한가.

## 알려진 한계

- Dinari의 준비금 감사보고서 원문, 수탁계좌 계약, 고객재산 분리와 도산절연 법률의견은 이번 공개자료 범위에서 확인하지 못했다.
- 한국 1단계 권리의 발행주체, 자본시장법상 분류, 해외 판매·외국환·세무는 구조별 외부 법률검토가 필요하다.
- 공개된 KRX·KSD·은행 운영 API가 아니므로 PoC는 서명된 모의 연동을 사용한다.
- 승인용 최종본은 아직 만들지 않았다. 이번 최종 후보에 대한 인간의 승인 또는 추가 수정결정이 필요하다.
