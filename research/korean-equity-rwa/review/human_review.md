# 인간 검토 메모

상태: **검토 준비 완료(review-ready)**
기준일: 2026-08-17
대상: 기관용 마스터 제안서와 저장소 루트의 세부 설계·구현 명세

## 이번 개정 결과

- 외국인 접근경로를 국내 직접계좌, 외국인 통합계좌, 해외 DR, ETF·펀드 간접노출과 합성·파생노출로 구분했다.
- 통합계좌를 유일한 접근경로가 아니라 국내 직접계좌 연결이 없는 해외 투자자에게 복수 KRX 종목을 제공하는 1단계 기준경로로 한정했다.
- “아직 남아 있는 마찰”을 한국시장 전체가 아니라 통합계좌 기반 수탁 권리상품의 운영범위로 좁혔다.
- 해외 DR을 가장 가까운 기존 상품 비교사례로 추가하고, 토큰이 예탁증서 또는 다른 증권으로 재분류될 가능성을 사업화 법률검토 게이트에 반영했다.
- 직접계좌와 해외 DR이 더 적절할 수 있다는 반론을 추가해 토큰화의 보편적 우월성을 전제하지 않았다.
- 기관용 최종 후보에서 대괄호 출처 ID를 모두 제거하고 자연어 출처표현과 주제별 공식 링크 목록으로 바꿨다.
- 구현 API·상태기계·스키마는 변경하지 않고 문제정의, 상품비교, 법률위험과 평가기준만 보강했다.

## 근거 검토

- 팀 자료와 제공된 Dinari PDF는 조사 단서로 사용하고, 운영·규제·상품 관련 결론은 금융위원회·법령정보센터·한국예탁결제원·한국거래소·한국은행·홍콩 SFC·미국 SEC·FINRA와 공식 제품문서로 별도 확인했다.
- 외국인 직접계좌는 금융위원회의 2023년 사전등록 폐지 자료와 2024년 계좌개설 실적으로 확인했다.
- 직접계좌 실적 1,432개는 2023년 12월 15일부터 2024년 6월 12일까지의 기간 한정 수치로 표시했다.
- 외국인 통합계좌의 운영구조와 실제 사례는 금융위원회의 2025년 가이드라인과 2026년 운영현황 설명으로 확인했다.
- 해외 DR의 원주 보관, 예탁증서 발행, 전환과 기업행동 구조는 한국예탁결제원 공식 안내로 확인했다.
- 한국예탁결제원 안내서의 2019년 말 종목 수와 종목 목록은 현재 현황으로 사용하지 않았다.
- ETF는 개별 주식이 아니라 펀드라는 상품 경계를 한국거래소 공식 설명으로 확인했다.
- 기존 Dinari, SEC, FINRA, 한국 토큰증권, 한국은행, 홍콩 SFC 근거와 해석 제한은 유지했다.

## 실행된 검증

- 로컬 설계 검증: JSON·JSONL·YAML, 스키마, fixture, 원본 체크섬, 로컬 링크와 PII 규칙 통과
- 최종 후보 가독성 검증: 구현 식별자·코드 마크업·대괄호 출처 ID 비포함 확인
- 접근경로 완결성 검증: 직접계좌·통합계좌·ADR/GDR·ETF/펀드·합성/파생 비교와 공식 참고자료 존재 확인
- Redocly: OpenAPI 유효
- AsyncAPI CLI: AsyncAPI 3.1.0 유효, governance issue 없음
- gherkin-lint: 핵심·실패 feature 통과
- RWA 리서치 validator: base 및 candidate gate 통과
- git diff whitespace 검사 통과

## 사람이 확인할 판단

1. 프로젝트 대상을 “국내 직접계좌 연결 없이 해외 판매기관을 통해 개별 한국주식에 접근하려는 투자자와 기관”으로 좁힌 것이 적절한가.
2. 직접계좌·통합계좌·해외 DR·간접노출 비교 후 통합계좌를 1단계 기준경로로 선택한 논리가 설득력 있는가.
3. 해외 DR과 기능적으로 유사할 수 있으나 동일 상품이라고 단정하지 않은 법적 경계가 충분히 명확한가.
4. 직접계좌 또는 기존 DR이 더 적절할 수 있다는 반론이 기관의 실제 의사결정에 도움이 되는가.
5. 본문 출처 ID를 제거하고 말미의 공식 자료 링크로 통합한 방식이 읽기 편한가.

## 알려진 한계

- 수탁 권리 토큰이 한국과 판매관할에서 예탁증서, 수익적 권리, 파생결합증권 또는 다른 증권 중 무엇으로 분류되는지는 외부 법률의견이 필요하다.
- 현재 이용 가능한 해외 DR의 종목별 목록, 유동성, 전환비용과 투자자별 실제 접근 가능성은 상품선정 단계에서 최신 데이터로 다시 비교해야 한다.
- 직접계좌의 국가·증권사별 원격개설 가능 여부, 구비서류와 비용은 기관별 정책과 투자자 유형에 따라 달라질 수 있다.
- Dinari의 준비금 감사보고서 원문, 수탁계좌 계약, 고객재산 분리와 도산절연 법률의견은 공개자료 범위에서 확인하지 못했다.
- 한국 1단계 권리의 발행주체, 자본시장법상 분류, 해외 판매·외국환·세무는 구조별 외부 법률검토가 필요하다.
- 승인용 최종본은 아직 만들지 않았다. 이번 최종 후보에 대한 인간의 승인 또는 추가 수정결정이 필요하다.
