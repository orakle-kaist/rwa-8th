# 4차 잔여 공백

| 공백 | 현재 처리 | 사업화 전 해소주체 |
|---|---|---|
| 수탁 권리의 증권분류·발행·중개·공시 | 단정하지 않고 복수 분류 가능성을 공개 | 한국·판매관할 법률자문, 감독당국 |
| 고객자산 분리·도산절연 | 코드나 1:1 문구로 보장하지 않음 | 발행·수탁 계약, 법률의견, 감사 |
| Dinari·Alpaca 비공개 내부화면 | 공개 API·가이드 기반 업무화면으로 표시 | 각 회사 또는 실사자료 |
| 실제 통합계좌·상임대리인·KRX·KSD·은행 연결 | 서명된 합성 어댑터로 제한 | 참여 증권사·수탁기관·은행·시장인프라 |
| 세무·외국환·국외이전 상세규칙 | 책임과 증거 위치만 설계 | 세무·외환·개인정보 자문과 기관 준법 |

위 공백을 확인하지 않은 상태에서는 PoC를 실제 거래, 운영승인 또는 투자상품으로 표현할 수 없다.
