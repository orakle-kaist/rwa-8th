# 보고서 구조 계약

## 필수 목차

1. 의사결정 요약
2. 접근경로와 기준 인프라 선택
3. Dinari 국제형·미국형 비교
4. 한국형으로 달라져야 하는 요소
5. 역할·계좌·권위장부 운영 모델
6. 투자자·토큰 운영자·브로커·수탁 업무화면
7. 통제와 기관별 인사이트
8. 위험·반론과 PoC 검증 계획
9. 단계별 추진과 사업화 게이트
10. 결론

## 작성 기준

- 각 절은 확인된 사실과 설계 선택을 구분한다.
- 기술 기능을 나열하지 않고 해당 기능이 줄이는 운영 위험을 설명한다.
- 사업화 가능성을 단정하지 않고 필요한 법률·규제·기관 검토를 가까이 표시한다.
- 홍콩은 사례이며 코어 시장이나 유일한 진출 경로로 표현하지 않는다.
- Dinari와 Alpaca의 회사 공개설명은 규제기관 확인사실 및 실제 내부 시스템과 구분한다.
- 마스터 문서는 구현 식별자 대신 기관이 이해할 수 있는 계좌·장부·책임 언어를 사용한다.
