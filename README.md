# Korean Equity RWA Institutional PoC

이 프로젝트는 외국인이 해외 금융기관을 통해 한국 상장주식에 투자할 때 필요한 구조를 제안합니다. Dinari의 수탁형 토큰화 주식을 참고하되 한국의 계좌, 주문, T+2 결제, 주식 보관, 권리 배정과 보고 방식에 맞게 다시 설계합니다.

현재는 **마스터 제안서 검토 단계**입니다. PoC 코드, 제품 요구사항 문서, 화면, 시스템 연결 방식, 상태 규칙과 스마트컨트랙트는 아직 확정하지 않았습니다. 실제 자금, 주식 또는 개인정보를 다루지 않으며 법률의견이나 기관의 승인을 대신하지 않습니다.

## 현재 기준 문서

[final_candidate.md](research/korean-equity-rwa/drafts/final_candidate.md)가 현재 단계의 **유일한 마스터 후보이자 판단 기준**입니다. 다음 문서는 마스터를 검토하기 위한 보조자료입니다.

- [리서치 브리프](research/korean-equity-rwa/brief.md): 조사 질문, 범위와 성공 기준
- [공식 출처 정리](research/korean-equity-rwa/sources/web/official-sources.md): 공개 근거와 확인 기준일
- [팀 제공 자료 인덱스](research/korean-equity-rwa/sources/notes/user-material-index.md): 원자료 위치, 체크섬과 반영 판단
- [내부 검토 메모](research/korean-equity-rwa/review/human_review.md): 승인 전에 결정할 사항과 알려진 한계

`_work/`에는 조사 과정과 검증 이력이 보관됩니다. 마스터 승인 전에 먼저 작성됐던 상세 설계와 기술 명세는 [pre-PRD v1 아카이브](archive/pre-prd-v1/README.md)로 옮겼습니다. 아카이브는 참고자료이며 현재 구현 기준이 아닙니다.

## 제안 구조

본 제안은 직접계좌나 기존 DR로 목적을 달성하기 어려우면서 해외 현지증권사를 통해 여러 한국 개별종목에 접근하려는 고객을 다룹니다. 해외 증권사는 투자자 확인, 국내 통합계좌 명의와 고객별 권리장부를 맡습니다. 국내 주문집행 증권사는 KRX 주문을 처리하고 별도 수탁은행은 상임대리인을 겸해 보관계좌와 권리업무를 맡습니다. T+2 결제와 국내 보관이 확인된 수량만큼만 토큰화된 권리를 발행합니다.

PoC는 같은 주문을 투자자, 해외 증권사, 국내 증권사, 수탁은행과 기술운영자의 관점에서 보여줍니다. 계약상 권리를 책임지는 기관과 국내 주식을 보관하는 기관을 구분하고, 국내 수탁수량, 해외 투자자별 권리 합계와 토큰 수량이 계속 일치하는지 확인합니다. 공개된 Dinari와 Alpaca 자료를 참고하지만 실제 내부 화면이나 실제 연계를 재현한다고 주장하지 않습니다.

## 저장소 구조

```text
research/korean-equity-rwa/
  brief.md                  조사 질문, 범위와 성공 기준
  drafts/final_candidate.md 현재 단계의 유일한 마스터 후보
  sources/                  공식 출처, 팀 제공 원자료와 인덱스
  review/human_review.md    내부 검토 사항과 알려진 한계
  _work/                    조사 과정과 검증 이력
archive/pre-prd-v1/         마스터 승인 전에 만든 과거 설계의 참고용 보관소
scripts/                    현재 문서와 연구 자료를 확인하는 검증기
PROJECT_WORKFLOW.md         단계별 산출물과 승인 기준
```

후속 문서와 폴더는 마스터가 승인되고 해당 단계가 시작될 때 만듭니다. 자세한 순서는 [프로젝트 산출물과 승인 순서](PROJECT_WORKFLOW.md)를 따릅니다.

## 현재 상태

- 현재 단계: 마스터 검토
- 리서치 사실 확인 기준일: 2026-08-17, 한국 시간
- PoC 구현: 시작 전
- 마스터 승인: 팀 검토 대기
- 외부 기관 검증: 수행하지 않음

팀원은 증권사, 수탁기관, 은행, 해외 판매기관, 법무, 감사와 투자자 역할을 나눠 내부 검토합니다. 이는 기관 관점에서 가설을 점검하는 활동이며 실제 기관 검토나 제도 적합성 확인이 아닙니다.
