# Korean Equity RWA Institutional PoC

이 프로젝트는 비거주 일반 개인투자자가 해외 금융기관을 통해 한국 상장주식에 투자할 때 필요한 구조를 제안합니다. Dinari의 수탁형 토큰화 주식을 참고하되 한국의 법적 증권 장부, 외국인 통합계좌, T+2 결제와 권리관리 방식에 맞춰 `한국형 규제 수탁 권리의 24/7 2차시장 통제`를 설계합니다.

마스터 제안서는 2026년 8월 29일 팀 내부 기준으로 승인했습니다. 현재는 **PoC 목표와 성공 기준을 확정하는 2단계**입니다. PoC 코드, 제품 요구사항 문서, 화면, 시스템 연결 방식, 상태 규칙과 스마트컨트랙트는 아직 확정하지 않았습니다. 실제 자금, 주식 또는 개인정보를 다루지 않으며 법률의견이나 기관의 승인을 대신하지 않습니다.

## 제안 구조

본 제안은 인가 해외 증권사와 연결된 토큰 플랫폼에서 KOSPI 200의 여러 개별종목에 접근하려는 비거주 일반 개인투자자를 다룹니다. 토큰 플랫폼은 투자자 앱, 주문 요청 흐름, 권리 계산, 토큰 생애주기와 기관 업무화면을 주도합니다. 인가 해외 증권사는 투자자와 직접 증권계좌 계약을 맺고 판매 가능 판정, 주문 접수, 고객자산, 국내 통합계좌 명의와 고객별 수탁권리 원장을 책임합니다. 국내 주문집행 증권사는 KRX 주문을 처리하고 별도 수탁은행은 상임대리인을 겸해 보관계좌와 권리업무를 맡습니다. 고객은 해외 증권사 고객계좌의 USD 잔액 또는 확인된 지갑의 USDC를 주문자금으로 사용하고, 국내 주식은 인가 기관이 마련한 KRW로 결제합니다. 고객자금과 KRX 체결을 확인하면 인가 해외 증권사가 고객 권리기입을 승인하고 토큰 플랫폼이 체결수량의 토큰을 발행하며, T+2까지 국내 결제 대기로 따로 표시합니다.

PoC 대상은 2026년 8월 28일 KRX 공식 KOSPI 200 구성종목 전체입니다. 기준일에는 회사분할에 따른 일시적 변화를 포함해 서로 다른 종목코드 201개가 있습니다. 모든 종목에 같은 적격성, 결제 완료 재고, 지정가, 위험한도와 거래중지 규칙을 적용합니다. 삼성전자, SK하이닉스, SK텔레콤, 현대차, NAVER와 미래에셋증권에는 모의 지정 마켓메이커 재고와 호가를 넣어 정상체결, 부분체결, 위험중지와 기업행동을 상세 시연합니다.

현재 PoC인 1단계는 해외 계약상 권리 레일만 새로 만들고 한국주식의 거래, 결제와 보관은 기존 KRX, KSD와 통합계좌를 사용합니다. 직접계좌형 토큰화도 가능하지만 24/7 거래마다 국내 투자자별 법정 계좌부를 변경하는 별도 시장구조가 필요합니다. 이번 PoC는 국내 통합 보유총량을 유지한 채 해외 고객별 수탁권리만 재배분할 수 있어 통합계좌형을 선택합니다. 체결 직후 발행된 토큰은 T+2까지 결제 대기로 잠그고 국내 결제가 끝난 권리만 하나의 인가 해외 증권사 안에서 적격 투자자와 지정 마켓메이커 사이에 24/7 지정가로 거래합니다. 고객별 수탁권리 원장, 토큰, 자금과 마켓메이커 재고가 함께 바뀌고 국내 통합 보유총량은 유지돼야 합니다.

현금배당, 의결권 지시와 환매는 기존 기관 생애주기를 유지합니다. 24/7 1차 발행 및 환매 완료, 외부 은행 입금, 오프아워 USD/KRW 환전과 신규 기초주식 매수는 제외합니다. 실제 유동성, 스프레드 경쟁력, 마켓메이커 참여 의사, 인허가 적합성과 운영비 절감도 이 합성 데이터 PoC가 증명하지 않습니다.

분산원장이 법적 증권 계좌부가 되는 2단계는 2027년 제도 시행과 세부 인프라 준비 뒤 검토할 별도 전망입니다. 이번 PoC는 2단계 화면이나 거래를 구현하지 않습니다. 기존 상장주식이나 1단계 권리토큰이 자동 전환된다고 가정하지 않습니다.

PoC는 같은 거래 생애주기를 투자자, 토큰 플랫폼, 인가 해외 증권사, 지정 마켓메이커, 국내 증권사와 수탁은행의 관점에서 보여줍니다. Dinari의 제휴 플랫폼은 투자자 화면과 주문 접점을 제공하는 고객채널이라는 점에서 인가 증권사와 구분합니다. 계약상 권리를 책임지는 기관과 국내 주식을 보관하는 기관을 나누고, 국내 수탁수량, 해외 증권사의 고객별 수탁권리 합계, 토큰 수량과 자금이 계속 일치하는지 확인합니다. 공개된 Dinari와 Alpaca 자료를 참고하지만 실제 내부 화면, 체결품질이나 비공개 가격 및 헤지 모델을 재현한다고 주장하지 않습니다.

문서에서 토큰 1차시장은 KRX에서 이미 발행된 기초주식을 취득해 권리와 토큰을 발행하거나 환매로 종료하는 과정이고, 토큰 2차시장은 결제 완료된 기존 권리토큰의 제한 이전입니다. 후속 다중체인은 LayerZero V2 OFT Burn&Mint를 원칙으로 하지만 브리지 실행은 단일체인 1단계 PoC에 포함하지 않습니다.

토큰 표준, 발행할 블록체인과 가격 및 결제 정보를 전달하는 방식은 마스터나 PRD에서 미리 정하지 않습니다. PRD가 필요한 동작을 확정한 뒤 6단계 시스템 구조와 보안 설계에서 기술을 선택하고, 8단계 스마트컨트랙트 설계에서 세부 권한과 동작을 정합니다.

## 현재 상태

- 현재 단계: 2단계 PoC 목표와 성공 기준 정리
- 2단계 승인: 팀 검토 대기
- 리서치 사실 확인 기준일: 2026-08-28, 한국 시간
- PoC 구현: 시작 전
- 마스터 승인: 2026-08-29 팀 내부 승인 완료
- 외부 기관 검증: 수행하지 않음

팀원은 증권사, 수탁기관, 은행, 해외 판매기관, 법무, 감사와 투자자 역할을 나눠 내부 검토합니다. 이는 기관 관점에서 가설을 점검하는 활동이며 실제 기관 검토나 제도 적합성 확인이 아닙니다.
