# Korean Equity RWA Institutional PoC

이 프로젝트는 비거주 일반 개인투자자가 해외 금융기관을 통해 한국 상장주식에 투자할 때 필요한 구조를 제안합니다. Dinari의 수탁형 토큰화 주식을 참고하되 한국의 법적 증권 장부, 계좌, 주문, T+2 결제, 주식 보관, 권리 배정과 보고 방식에 맞게 다시 설계합니다.

현재는 **마스터 제안서 검토 단계**입니다. PoC 코드, 제품 요구사항 문서, 화면, 시스템 연결 방식, 상태 규칙과 스마트컨트랙트는 아직 확정하지 않았습니다. 실제 자금, 주식 또는 개인정보를 다루지 않으며 법률의견이나 기관의 승인을 대신하지 않습니다.

[final_candidate.md](research/korean-equity-rwa/drafts/final_candidate.md)가 현재 단계의 **유일한 마스터 후보이자 판단 기준**입니다. 다음 문서는 마스터를 검토하기 위한 보조자료입니다.

- [리서치 브리프](research/korean-equity-rwa/brief.md): 조사 질문, 범위와 성공 기준
- [공식 출처 정리](research/korean-equity-rwa/sources/web/official-sources.md): 공개 근거와 확인 기준일
- [팀 제공 자료 인덱스](research/korean-equity-rwa/sources/notes/user-material-index.md): 원자료 위치, 체크섬과 반영 판단
- [내부 검토 메모](research/korean-equity-rwa/review/human_review.md): 승인 전에 결정할 사항과 알려진 한계

`_work/`에는 조사 과정과 검증 이력이 보관됩니다. 마스터 승인 전에 먼저 작성됐던 상세 설계와 기술 명세는 [pre-PRD v1 아카이브](archive/pre-prd-v1/README.md)로 옮겼습니다. 아카이브는 참고자료이며 현재 구현 기준이 아닙니다.

## 제안 구조

본 제안은 직접계좌나 기존 DR로 투자 목적을 충족하기 어렵고, 해외 현지증권사를 통해 KOSPI 200의 여러 개별종목에 접근하려는 비거주 일반 개인투자자를 다룹니다. 투자자는 판매 국가의 일반 고객 분류, 상품별 소매판매 요건과 고객확인을 통과해야 하며 자기주도 주문만 이용합니다. 해외 증권사는 판매 가능 판정, 국내 통합계좌 명의와 고객별 권리장부를 맡습니다. 국내 주문집행 증권사는 KRX 주문을 처리하고 별도 수탁은행은 상임대리인을 겸해 보관계좌와 권리업무를 맡습니다. 고객은 해외 증권사 고객계좌의 USD 잔액 또는 확인된 지갑의 USDC를 주문자금으로 사용하고, 국내 주식은 인가 기관이 마련한 KRW로 결제합니다. 고객자금과 KRX 체결을 확인하면 체결수량의 고객 권리와 토큰을 발행하고, T+2까지 국내 결제 대기로 따로 표시합니다.

PoC 대상은 목표 승인일 기준 KOSPI 200 구성종목 200개입니다. 모든 종목은 같은 주문, 권리기입, 발행, 결제 추적, 제한된 이전과 환매 흐름을 사용합니다. 이 가운데 대표 6종목만 서로 다른 제한과 예외를 보여주는 상세 시연에 사용합니다.

현재 PoC인 1단계는 해외 계약상 권리 레일만 새로 만들고 한국주식의 거래, 결제와 보관은 기존 KRX, KSD와 통합계좌를 사용합니다. 기초주식은 현행 전자등록계좌부에 남으므로 토큰 이전만으로 한국주식이 이전되거나 투자자가 발행회사 주주명부에 직접 기록되지는 않습니다. PoC는 발행에서 끝나지 않고 현금배당, 제한된 RFQ, 환매용 기초주식 매도, T+2 매도대금 결제, 권리와 토큰 소각 및 지급까지 하나의 생애주기로 검증합니다.

분산원장이 법적 증권 계좌부가 되는 2단계는 2027년 제도 시행과 세부 인프라 준비 뒤 검토할 별도 전망입니다. 이번 PoC는 2단계 화면이나 거래를 구현하지 않습니다. 기존 상장주식이나 1단계 권리토큰이 자동 전환된다고 가정하지 않습니다.

PoC는 같은 거래 생애주기를 투자자, 해외 증권사, 국내 증권사, 수탁은행과 기술운영자의 관점에서 보여줍니다. 계약상 권리를 책임지는 기관과 국내 주식을 보관하는 기관을 구분하고, 국내 수탁수량, 해외 투자자별 권리 합계와 토큰 수량이 계속 일치하는지 확인합니다. 공개된 Dinari와 Alpaca 자료를 참고하지만 실제 내부 화면이나 실제 연계를 재현한다고 주장하지 않습니다.

토큰 표준, 발행할 블록체인과 가격 및 결제 정보를 전달하는 방식은 마스터나 PRD에서 미리 정하지 않습니다. PRD가 필요한 동작을 확정한 뒤 6단계 시스템 구조와 보안 설계에서 기술을 선택하고, 8단계 스마트컨트랙트 설계에서 세부 권한과 동작을 정합니다.

```text
research/korean-equity-rwa/

  _work/                    조사 과정과 검증 이력

scripts/                    현재 문서와 연구 자료를 확인하는 검증기
```

## 현재 상태

- 현재 단계: 마스터 검토
- 리서치 사실 확인 기준일: 2026-08-25, 한국 시간
- PoC 구현: 시작 전
- 마스터 승인: 팀 검토 대기
- 외부 기관 검증: 수행하지 않음

팀원은 증권사, 수탁기관, 은행, 해외 판매기관, 법무, 감사와 투자자 역할을 나눠 내부 검토합니다. 이는 기관 관점에서 가설을 점검하는 활동이며 실제 기관 검토나 제도 적합성 확인이 아닙니다.
