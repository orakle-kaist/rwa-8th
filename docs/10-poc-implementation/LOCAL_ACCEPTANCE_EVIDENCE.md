# 전체 시연과 로컬 인수시험 구현 증거

상태: **로컬 통합 정합성 보완 완료, Fuji 검증 대기**

이 문서는 로컬 시연 후보의 검증 범위와 반복 가능한 증거 생성 방법을 기록한다. Fuji 사람시험 3개는 공식 ISIN 확인 전까지 실행하지 않는다.

재검토에서 확인한 공백은 모두 실행 경로에서 보완했다. 76개 시험번호는 각자 실제 입력과 판정을 수행하고, 175개 상태 전환표는 데이터베이스 상태변경 때 강제된다. 플랫폼 API 43개를 모두 구현했으며, 주요 생애주기는 실제 PostgreSQL, Anvil 계약과 서명된 모의 기관 결과를 함께 사용한다. 체인 거래만 성공한 상태는 업무 완료로 보지 않는다.

## 구현한 내용

- 투자자 앱과 통합 기관 콘솔 상단에 `고객 준비 → 1차 발행 → T+2 → 24/7 제한 거래 → 시장조성자 헤지 → 환매 → 권리업무` 진행표를 추가했다.
- 각 단계는 쉬운 한국어 상태, 담당기관, 기준 기록, 차단 사유와 다음 행동을 먼저 보여주고 기계 상태코드는 상세정보에 둔다.
- 기관 콘솔은 해외 증권사, 시장조성자, 수탁·권리, 준법·감사 업무공간을 구분하고 업무 ID별 기관 요청과 기준 기록을 추적한다.
- `24/7`의 의미, 토큰이 고객 권리 기준장부가 아니라는 경계와 모든 데이터가 모의라는 설명을 고정했다.
- [구현 시험 추적표](specs/implementation-test-map.json)에 76개 로컬 시험의 주 실행파일·정확한 시험명, 보조 실행계층, 기대결과와 요구사항·상태·API·이벤트·계약 추적을 기록했다.
- 76개 시험은 그룹 설명을 반복 확인하지 않는다. 각 시험번호가 자신의 입력값, 허용·금지 상태전환, 수량·금액 경계 또는 계약 통제를 직접 실행한다. PostgreSQL, Anvil·Foundry와 Chromium의 보조 시험은 같은 업무를 실제 저장·체인·화면 계층에서 다시 검증한다.
- [상태 전환표](specs/state-transition-matrix.json)에 승인된 175개 상태와 허용 전환, 대표 금지 전환 및 `STATE_CONFLICT` 결과를 기록했다.
- 명세 검증기는 49개 요구사항, 175개 상태, OpenAPI 48개, AsyncAPI 8개와 계약 함수·이벤트·오류·역할·불변식의 양방향 연결을 검사한다.
- 필수시험의 `skip`, `todo`, 조건부 무시, 자동 재시도, 중복 주 실행시험과 존재하지 않는 시험 위치를 차단한다.
- 1차 발행, 24/7 제한 거래, 시장조성자 헤지, 환매, 지갑복구와 기업행동은 실제 Anvil 영수증을 남긴다.
- 모의 국내 주문, 결제, 수탁과 권리업무는 등록된 프로세스 수명 Ed25519 공개키로 검증된 결과만 상태를 전환한다.
- 보유내역, 활동내역과 업무 타임라인 API는 권리, 자금, 기관사실, 체인 영수증과 격리 계보를 같은 업무 ID로 연결한다.

## 반복 실행

로컬 합성 시연 DB는 다음처럼 명시적 확인값을 전달해야만 초기화할 수 있다.

```bash
DATABASE_URL=postgresql://rwa:rwa@127.0.0.1:5432/rwa_poc \
  pnpm demo:reset -- --confirm=RESET_LOCAL_SYNTHETIC_RWA_POC
```

초기화 도구는 호스트와 데이터베이스 이름을 검사한다. UI에는 초기화 기능이 없고 실제 또는 이름이 다른 데이터베이스에는 실행되지 않는다.

전체 인수시험은 깨끗한 커밋에서 다음 명령으로 실행한다.

```bash
pnpm test:acceptance
```

이 명령은 전체 로컬 검증 뒤 76개 시험을 독립된 이름으로 다시 실행한다. 결과는 git에서 제외된 `evidence/local/<testRunId>/`에 저장한다. `actual-lifecycle.json`에는 실제 Anvil 거래해시, 업무 유형, 체인 단계, 모의 기관 서명 이벤트 수와 토큰 공급량 대사가 기록된다.

## 증거 범위

- 실행 커밋, 시작·종료시각과 명령별 종료코드 및 로그
- 구현 추적표와 fixture 체크섬
- 76개 시험별 결과, 실행파일과 실행시간
- 201개 공식 후보와 대표 6종목 비활성, 합성 상품 `990001`, `990002`, `990003`만 사용한다는 대사 결과
- PostgreSQL 수량 대사, 실제 Anvil 거래 영수증, 검증된 모의 기관 이벤트와 Playwright Chromium 화면 검증 결과

개인정보, 개인키, 전체 인증토큰과 전체 서명은 증거에 저장하지 않는다. 로컬 결과는 실제 규제 허용, 유동성, 가격 공정성 또는 Fuji 배포 성공을 뜻하지 않는다.

## 로컬 게이트 결과와 남은 게이트

- 175개 상태 런타임 강제와 플랫폼 API 43개 구현: 완료
- 실제 Anvil 계약과 모의 기관 서명 이벤트를 통한 전체 생애주기 연결: 완료
- 76개 시험번호별 실행판정과 9개 Chromium 생애주기: 완료
- 실제 Anvil 영수증 55건, 서명된 기관 이벤트와 세 합성 토큰 공급량 대사: 완료
- 대표 6종목 공식 ISIN 확인, Fuji 배포와 사람시험 3개: 미실행
