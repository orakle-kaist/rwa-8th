# 고객·상품·투자자 보호 구현 증거

상태: **기능 구현 완료, 사용자 검토 대기**

이 문서는 10단계 세 번째 기능의 코드와 검증 결과를 기록한다. 모든 고객, 기관, 지갑과 민원은 합성이며 실제 개인정보나 자산을 사용하지 않는다.

## 구현된 흐름

| 설계 대상           | 구현 결과                                                                                            | 완료 판단                                                                                   |
| ------------------- | ---------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| 고객확인과 보호판정 | 허용, 거절과 만료 프로필을 PostgreSQL에 보존하고 공시 동의 및 전용 지갑 상태와 함께 준비상태 계산    | 유효 고객판정, 현재 공시 동의와 체인 반영이 끝난 전용 지갑이 모두 있어야 주문·권리수령 가능 |

## 기준정보와 개인정보 경계

- 기준 버전은 `KOSPI200-2026-08-28`, 공시 버전은 `SIM-RISK-2`다.
- KRX 원본에 없는 ISIN과 토큰 주소는 추측하지 않고 비워 둔다.
- 투자자 공동 화면과 API에는 여권, 국적, 계좌번호, 제재조회 원문이나 개인키를 저장·표시하지 않는다.
- 상품과 고객 화면에는 `모의 환경`을 고정 표시한다.
- 고객의 기준 권리는 계속 인가 해외 증권사의 고객별 수탁권리 원장에 있으며 온체인 적격성은 지갑의 이전 가능 판정만 나타낸다.

## 자동시험 범위

- 단위시험: 고객 판정, 공시 누락·만료, 민원 상태전환과 책임기관 분류
- PostgreSQL: 201개 반복 적재, 동의 멱등성, 지갑 승인·체인 반영·교체 동결, 고객별 민원 격리와 감사기록
- API: 201개 페이지 조회, `202 Accepted`, 멱등 충돌, 지갑 서명 위조와 다른 고객의 민원 조회 차단
- Anvil: 권한 있는 작업자의 적격성 등록과 실제 체인 조회
- Playwright Chromium: 허용·거절·만료 고객, 공시·지갑 접수, 민원 접수부터 기관 배정·답변·정정 검토·종결까지, 대표 종목과 전체 차단 사유 및 두 화면군의 모의 표시

## 남은 범위

상품은 아직 하나도 활성화하지 않았고 전 종목 거래기능은 차단했다. 공식 ISIN 확인과 Fuji 대표 6종목 배포는 마지막 배포 단계에서 수행한다. 다음 기능은 USD와 USDC 1차 지정가 주문, 종목과 가격 및 거래일별 취합, 정수 비례배분, 결제 대기 선발행과 국내 결제 및 수탁 이중 확인이다.
