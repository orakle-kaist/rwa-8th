# 제한형 토큰 기반 구현 증거

상태: **기능 구현 완료, 사용자 검토 대기**

이 문서는 10단계 두 번째 기능의 코드와 검증 결과를 기록한다. 로컬 Anvil과 합성 계정만 사용했으며 Fuji 배포나 실제 자산 처리를 뜻하지 않는다.

## 구현된 기반

| 설계 대상              | 구현 위치                                 | 확인 내용                                                                                       |
| ---------------------- | ----------------------------------------- | ----------------------------------------------------------------------------------------------- |
| 종목별 제한형 권리토큰 | `contracts/src/RestrictedEquityToken.sol` | 소수점 0, 일반 이전과 승인 차단, 다섯 수량 상태, 적격 투자자와 지정 시장조성자 사이의 제한 이전 |
| 적격성                 | `contracts/src/EligibilityRegistry.sol`   | 적격 여부, 시장조성자 여부, 만료와 철회만 저장하고 고객 원문정보는 저장하지 않음                |
| 상품 배포              | `contracts/src/SecurityTokenFactory.sol`  | 6자리 숫자 종목코드와 12자리 ISIN 형식, 종목·ISIN·설계버전 중복 방지, CREATE2 배포와 주소 조회  |
| 서명 의사              | `contracts/src/IntentVerifier.sol`        | 승인된 다섯 EIP-712 형식, EOA와 ERC-1271, 정책버전, 만료와 nonce 재사용 차단                    |
| 시장정책               | `contracts/src/MarketPolicyRegistry.sol`  | 종목별 업무 중지, USDC 경로 중지, 전역 긴급중지와 정책버전                                      |
| 관리구조               | `contracts/script/DeployFoundation.s.sol` | 실제 Safe 3개 관리자 중 2개 승인, OpenZeppelin 60초 지연 실행, 지연 계약만 기반 계약 관리자     |

발행 증거를 결합하는 컨트롤러, USD와 USDC 정산, 환매 지급청구와 기업행동 독립승인은 아직 구현하지 않았다. 이 기능은 후속 컨트롤러가 호출할 토큰과 검증 기반까지만 제공한다.

## ABI 검증

- `contract-abi.json`의 기존 64개 함수, 38개 이벤트와 16개 오류는 고객·기관 업무 ABI로 유지했다.
- `governance-abi.json`은 표준 역할관리, 정책 조회, 상품주소 조회와 해외 증권사 정산 서명자 관리를 별도로 정의한다.
- 컴파일된 다섯 기반 계약의 공개 함수와 이벤트는 업무 ABI와 관리 ABI의 합집합과 정확히 일치해야 한다. 승인되지 않은 공개 항목이 생기면 검증이 실패한다.
- Solidity 구조체, `bytes16` 업무 식별자, `bytes32` 증거와 정책, `uint256` 수량·금액·nonce 자료형도 업무 ABI와 대조한다.

## 자동시험 결과

| 시험                   | 결과                                                                                                    |
| ---------------------- | ------------------------------------------------------------------------------------------------------- |
| Foundry 단위·퍼징      | 일반 이전, 무권한 실행, 부적격 지갑, 상품 중복과 형식, 서명 위조·만료·재사용, 복구와 분할을 포함해 통과 |
| Foundry handler 불변식 | 128회 실행, 8,192개 임의 호출, 되돌림 0건으로 전체 발행량과 다섯 상태 합계 일치                         |
| Safe와 지연 실행       | Safe 서명 1개 실패, 2개 예약 성공, 60초 전 실행 실패와 이후 실행 성공                                   |
| viem·Anvil             | 적격성, 정책과 종목 토큰을 실제 로컬 체인에 배포하고 명칭, 기호, 소수점과 공급량 조회 성공              |
| 전체 로컬 게이트       | 문서·명세, 타입, PostgreSQL, Anvil, 단위·통합 및 Chromium 화면 시험 통과                                |

실제 Safe 배포 도우미도 로컬 Anvil에서 실행해 Safe, 지연 실행, 적격성, 정책, 서명 검증기와 상품 팩토리 주소가 각각 생성되는 것을 확인했다. 로컬 주소와 합성 키는 재현 가능한 시험값이므로 Fuji 배포 증거로 보존하지 않는다.
