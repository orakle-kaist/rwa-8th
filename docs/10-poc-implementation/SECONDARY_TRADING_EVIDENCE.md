# 24/7 제한 거래 구현 증거

상태: 기능 구현 및 전체 로컬 검증 완료, 사용자 검토 대기

## 구현 범위

- 공식 KOSPI 200 후보 201개와 분리된 메인 합성 상품 `990001 모의 삼성전자 수탁권리`
- `990002`는 가격·위험·부분체결 회귀시험용 계약으로만 유지하고 투자자 상품목록에서는 숨김
- 별도 권리계정, 지갑과 USD·USDC 시험잔액을 가진 지정 시장조성자
- 결제완료 100주, 결제 대기 20주와 순포지션 0주의 합성 시작상태
- 30초 만료 지정가 호가와 투자자 주문의 EIP-712 서명 검증
- 결제완료 수탁권리와 자금의 PostgreSQL 예약 및 동시 주문 직렬화
- USD 고객장부 정산과 6자리 시험 USDC 원자적 DvP의 분리
- 투자자와 지정 시장조성자 사이에서만 가능한 제한형 토큰 이전
- 부분체결 1회, 미체결 잔량 해제와 세 서명 nonce 재사용 차단
- 권리 원장, 토큰과 자금 확인 뒤 업무 완료 및 시장조성자 재고·순포지션 갱신
- 체인 성공 뒤 권리 원장 실패 격리와 같은 기관 결과의 멱등 재처리
- RPC 응답 유실 시 거래해시 확인 전 재전송 금지
- 투자자 앱의 로컬 거래 시험과 통합 기관 콘솔의 호가·재고·정산 대기열

## 대표 시나리오

지정 시장조성자가 `SIM990001`의 USDC 매도호가를 1주당 187.12 USDC, 5주로 게시한다. 투자자 B가 8주를 주문하면 5주만 체결하고 3주는 취소한다. 완료 뒤 시장조성자의 결제완료 재고는 100주에서 95주로, 순포지션은 0주에서 -5주로 바뀐다. 결제 대기 20주는 처음부터 끝까지 거래에 사용되지 않는다. 이 거래는 같은 `990001`에서 앞서 발행·T+2가 끝난 고객권리와 연결된다.

## 통제 경계

- `990001`은 실제 삼성전자 주식이나 공식 ISIN 판매상품이 아니다. `990002`는 투자자 화면에 노출하지 않는 회귀시험 전용이다.
- USDC 장부의 예약수량은 지갑 잔액과 사용승인을 반영한 모의 예약 기록이지, 사전 에스크로 입금을 뜻하지 않는다. 실제 시험 USDC와 권리토큰은 같은 체인 거래에서 이동한다.
- USD 경로는 해외 증권사의 모의 고객자금 장부에서 권리와 자금을 하나의 데이터베이스 거래로 확정한다.
- 체인 거래 성공만으로 업무를 완료하지 않는다. 인가 해외 증권사의 고객별 수탁권리 원장 반영까지 확인한다.
- 국내 통합계좌 총보유량과 토큰 총발행량은 2차거래 전후 바뀌지 않는다.
- 기본 로컬 시연은 실제 Anvil 정산 컨트롤러를 호출하고 거래 영수증을 확인한다. 그래도 고객별 수탁권리 원장과 체인 사이의 법적 원자성을 주장하지 않는다.
- 가격 적정성, 실제 유동성, 시장조성자 수익성과 규제 허용은 이 기능이 입증하지 않는다.

## 위험 통제

- 순포지션 절댓값 20주는 허용하고 21주는 차단한다.
- 정보 나이 60초는 허용하고 61초는 차단한다.
- USDC/USD 0.9950~1.0050 범위 밖에서는 USDC 경로만 중지한다.
- 반쪽 스프레드 1.50% 초과와 종목별 또는 전체 손실한도 도달 시 신규 호가와 체결을 차단한다.
- 온체인 실행 전 실패는 예약을 해제한다. 체인 성공 뒤 권리 원장 실패는 임의 역이전하지 않고 요청을 격리한다.
