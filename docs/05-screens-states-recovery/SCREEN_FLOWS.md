## 1. 이 문서가 정하는 것

이 문서는 투자자와 기관 담당자가 PoC에서 무엇을 보고 어떤 판단과 행동을 해야 하는지 정한다. 색상, 글꼴과 픽셀 단위 배치는 정하지 않는다. 구현자가 상태, 책임기관이나 기준 기록을 새로 해석하지 않도록 화면의 목적, 표시할 증거, 가능한 행동과 차단 사유를 고정한다.

[업무 상태와 전환 규칙](STATE_MODEL.md)의 모든 상태는 하나 이상의 화면에서 확인할 수 있어야 한다. KSD와 자금 및 환전기관의 결과는 별도 사용자 화면을 만들지 않고 관련 기관 화면의 모의 외부 응답으로 표시한다.

PoC는 두 화면군으로 구성한다.

- `투자자 앱`: 고객확인과 투자자 보호, 상품조회, 1차 발행, 24/7 2차거래, 보유권리, 환매, 권리업무와 민원 안내를 보여준다.
- `통합 기관 콘솔`: 토큰 플랫폼, 인가 해외 증권사, 국내 주문집행, 수탁은행과 상임대리인, 지정 시장조성자, 준법과 감사 담당의 업무공간을 제공한다.

기관 콘솔의 역할 전환은 시연 편의를 위한 화면 전환이다. 실제 담당자의 실행권한이나 승인권한을 바꾸지 않는다. 실행, 승인과 독립 검토는 [기관 업무와 책임 설계](../04-institution-design/INSTITUTION_WORKFLOWS.md)에 따라 분리한다.

## 2. 모든 화면의 공통 원칙

### 2.1 항상 보여줄 정보

| 항목 | 투자자 앱 | 통합 기관 콘솔 |
|---|---|---|
| 모의 환경 표시 | 실제 주문, 자금, 주식 또는 기관연계가 아니라는 고정 안내 | 화면 상단에 `모의 기관연계` 표시와 외부 응답별 모의 표시 |
| 현재 기준시각 | 가격, 호가, 잔액과 진행상태의 기준시각 | 원본 기준시각과 플랫폼 수신시각을 구분 |
| 현재 상태 | 쉬운 한국어 상태와 다음 단계 | 업무별 상태축, 책임기관과 다음 승인 |
| 차단 사유 | 무엇이 막혔고 고객이 할 수 있는 다음 행동 | 영향범위, 원인 기록, 책임자와 재개조건 |
| 책임 구분 | 토큰 플랫폼, 해외 증권사와 국내기관의 역할 | 실행자, 승인자, 기준 기록 관리기관과 감사 담당 |
| 추적 | 고객이 이해할 수 있는 주문과 활동 흐름 | 원요청부터 정정, 기관 응답과 최종 결과까지 이어지는 증거 흐름 |

### 2.2 표시하지 않을 정보

- 실제 개인정보, 신분증 이미지, 제재조회 원문과 월별 보고서 본문
- 지갑 비밀정보, 기관 인증정보와 실제 고객자금 계좌번호
- 토큰 장부가 고객 권리나 한국주식의 법적 장부라는 표현
- 실제 KRX, KSD, 은행 또는 수탁기관과 연결됐다는 표현
- Dinari, Alpaca, Circle이나 특정 기관의 실제 내부화면을 복제했다는 표현
- 실제 가격의 공정성, 체결품질, 시장조성자 수익성과 규제 적합성을 입증했다는 표현

### 2.3 공통 차단 안내

차단 안내는 단순히 `오류`라고 쓰지 않는다. 다음 내용을 함께 보여준다.

1. 차단된 업무와 영향받은 종목, 고객 또는 자금경로
2. 현재까지 완료된 단계와 아직 완료되지 않은 단계
3. 자동으로 해제되는지 사람이 확인해야 하는지
4. 책임기관과 확인할 기준 기록
5. 다음 확인 예정시각 또는 재개조건

## 3. 전체 화면 이동 흐름

### 3.1 투자자 앱

```text
고객확인, 투자자 보호와 지갑
  → 상품목록
    → 종목 상세
      ├─ 1차 발행 주문 → 발행 진행내역 → 보유권리
      └─ 24/7 주문 → 2차거래 진행내역 → 보유권리

보유권리
  ├─ 환매 요청 → 환매 진행내역
  └─ 배당과 의결권 → 권리업무 상세

모든 화면
  → 차단과 조치 안내 → 해당 업무 진행내역 또는 민원, 고객지원 안내
```

### 3.2 통합 기관 콘솔

```text
전체 업무현황
  ├─ 토큰 플랫폼 운영
  ├─ 인가 해외 증권사
  ├─ 국내 주문집행
  ├─ 수탁과 상임대리
  ├─ 지정 시장조성자
  └─ 준법과 감사

각 업무공간
  → 요청 상세 → 기준 기록과 기관 응답 → 실행 또는 승인 → 증거 흐름

예외 발생
  → 예외 대기열 → 영향범위와 증거 → 보정 → 전체 재대사 → 독립 재개 승인
```

## 4. 투자자 앱 화면

### 4.1 고객확인, 투자자 보호와 전용 지갑

| 구분 | 화면명세 |
|---|---|
| 목적 | 합성 고객확인 결과와 함께 상품 이해도 및 필요한 적합성, 적정성 판정, 위험공시 동의, 고객 권리계정과 전용 지갑 연결을 확인한다. |
| 사용자 | 투자자 |
| 기준 기록 | 인가 해외 증권사의 고객 판매 가능 판정과 계좌 및 지갑 연결 승인 |
| 주요 정보 | 고객확인 허용, 거절, 만료, 상품 이해도와 필요한 적합성, 적정성 판정, 위험공시 버전, 전자 동의시각, 만료, 고객 참조번호, 전용 지갑 연결 여부 |
| 가능한 행동 | 모든 판정과 동의가 유효한 고객의 상품목록 이동, 지갑 연결, 교체 검토 요청, 민원창구 조회 |
| 금지된 행동 | 판정 또는 동의가 누락, 거절, 만료된 고객의 신규 주문과 권리 수령, 지갑 교체 후 승인 없는 권리 수령 |
| 차단 사유 | 고객확인, 투자자 보호 판정의 거절 또는 만료, 위험공시 동의 누락, 만료, 계좌 미승인, 지갑 미연결, 교체 검토 또는 기존 지갑 동결 |
| 다음 화면 | 상품목록 또는 차단과 조치 안내 |
| 감사 증거 | 판정기관, 정책과 위험공시 버전, 전자 동의시각과 유효기간, 승인시각과 지갑 연결 승인 |

```text
[모의 환경] 고객 준비상태
판매 가능 판정       허용 / 거절 / 만료
상품 이해도, 적합성    통과 / 검토 필요 / 실패
위험공시 동의         버전 00 / 유효 / 만료
유효기간             2026-00-00 00:00
고객 권리계정        연결 완료 / 미완료
전용 지갑            0x12...89  연결 완료 / 교체 검토

[상품목록 보기] [지갑 교체 검토 요청] [민원창구]
책임기관: 인가 해외 증권사
```

민원창구에서는 토큰 플랫폼의 기술 문의와 인가 해외 증권사가 처리할 증권계좌, 거래, 규제 민원을 구분한다. 투자자는 민원을 접수하고 본인 민원의 책임기관, 처리상태, 답변, 관련 주문, 적용한 위험공시 버전과 정정 업무를 조회한다. 기관 콘솔에서는 책임기관 배정, 답변 기록, 정정 연결과 종결을 수행한다.

### 4.3 종목 상세와 주문 경로 선택

| 구분 | 화면명세 |
|---|---|
| 목적 | 상품의 권리, 국내시장과 오프아워 거래의 차이 및 가능한 주문경로를 설명한다. |
| 사용자 | 투자자 |
| 기준 기록 | 승인된 상품기준정보, 시장정보와 해외 증권사의 상품정책 |
| 주요 정보 | 직접 주주명의가 아니라는 설명, 기준가격과 시각, KRX 세션, 1차 발행 및 환매 일정, 24/7 세션과 지정 시장조성자 |

| 차단 사유 | 해당 기능 중지, 오래된 가격, 중요사건, 외국인 한도 또는 고객 적격성 |
| 다음 화면 | 1차 발행 주문, 24/7 주문 또는 보유권리 |


### 4.4 1차 발행 주문과 자금 확인

| 구분 | 화면명세 |
|---|---|
| 목적 | 정수 수량의 기초주식 매수 요청과 USD 또는 USDC 자금경로를 확인한다. |
| 사용자 | 투자자 |
| 기준 기록 | 해외 증권사의 고객 주문과 USD 현금계좌, 전환사업자의 모의 USDC 확인 |
| 주요 정보 | 종목, 정수 수량, KRW 지정가격, 참고 USD 금액, 적용 환율, 자금경로, 예상 수수료, 예약금액, 해당 KRX 영업일 당일 유효조건, 취합과 부분체결 원칙, T+2 결제 대기 안내 |
| 가능한 행동 | 주문확인, 제출 또는 제출 전 취소 |
| 금지된 행동 | 시장가, 소수수량, 잔액을 넘는 주문, 미확인 USDC로 국내 주문 시작 |
| 차단 사유 | 고객 또는 상품 제한, USD 부족, USDC 미확인 또는 전환 실패, T+2 위험한도 부족 |
| 다음 화면 | 발행 진행내역 또는 종목 상세 |
| 감사 증거 | 고객 원주문, 자금예약, 위험공시 확인과 제출시각 |

USD는 고객 현금계좌에서 예약한다. USDC를 선택하면 수취 확인, USD 전환과 고객 USD 현금계좌 귀속을 보여준 뒤 같은 1차 주문 흐름으로 보낸다.

동일 종목, 동일 KRW 지정가격과 동일 거래일 주문만 같은 국내 주문으로 묶는다. 지정가격이 다르면 별도 주문으로 보낸다. KRX 휴장 중 접수한 요청은 다음 모의 KRX 영업일 대기열과 당일 유효조건을 함께 표시한다.

```text
1차 발행 주문                         [모의 주문]
종목                    삼성전자 005930
수량                    5주, 정수만 가능
KRW 지정가격             257,000 KRW
참고 USD 금액            000.00 USD
적용 환율 / 기준시각      1,380.3 / 00:00
자금경로                 USD / USDC
예상 수수료              00.00 USD
유효조건                 다음 모의 KRX 영업일 당일

[주문 제출]
```

### 4.5 1차 발행 진행내역

| 구분 | 화면명세 |
|---|---|
| 목적 | 고객주문부터 지정가격별 취합, 국내 체결, T+2 위험 승인, 권리기입 승인과 실제 원장 기입, 토큰 발행 및 T+2 전환을 순서대로 보여준다. |
