# Pre-PRD v1 archive

이 디렉터리는 마스터 제안서 승인 전에 작성되었던 상세 설계·명세·검증 도구를 `2026-08-20`에 동결한 스냅샷입니다. 이동 직전 기준 커밋은 `1b32615`입니다.

## 지위

- 이 자료는 **참고용이며 비규범적(non-normative)** 입니다.
- 현재 마스터 후보나 향후 승인될 PRD·화면·상태기계·API·스마트컨트랙트 설계를 덮어쓰지 않습니다.
- AI 구현 에이전트가 이 디렉터리를 구현 요구사항으로 사용해서는 안 됩니다.
- 다시 사용할 아이디어가 있다면 승인된 마스터와 단계별 상위 산출물에서 재도출하고, 해당 단계의 리뷰를 받아야 합니다.

## 포함 내용

- `design/`: 과거의 모듈형 상세 설계
- `specs/`: 과거의 API, 이벤트, 스키마, 상태기계, BDD와 fixture
- `tooling/`: 위 설계·명세 전용 검증기
- `.gherkin-lintrc`: 과거 BDD lint 설정

아카이브 내부의 상대경로, 우선순위 설명과 검증 명령은 당시 저장소 구조를 전제로 한 역사적 기록입니다. 현재 구조에 맞게 유지보수하지 않으며, 실행 가능성도 보장하지 않습니다.
